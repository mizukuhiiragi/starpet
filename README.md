# ⭐ StarPet (星の子)

> **Retro Virtual Pet (Tamagotchi) on Stellar & Soroban**  
> *"Raise pixel star pets, hold tea parties, and immortalize their departure into personalized handwritten constellation NFTs."*

---

## 🌟 Concept (世界観・コンセプト)

**StarPet** is a nostalgic, low-friction Web3 virtual pet game designed to complement **StarPocket** (the non-custodial Stellar smart wallet).

Unlike speculative GameFi models that collapse under unsustainable tokenomics, StarPet adopts a **"Pure Emotional & Artistic Cycle"**:
1. **Retro 16×16 LCD Screen**: Zero cognitive burden, nostalgic 90s aesthetic (Tamagotchi / Digital Monster vibe).
2. **Peaceful Tea Parties (すれちがい通信)**: No combat stress. Socialize with friends over tea to foster faster growth.
3. **The Graduation Ceremony (旅立ちの星座式)**: When your pet reaches the end of its lifespan, it metamorphoses from a humble pixel sprite into a breathtaking celestial constellation.
4. **Handwritten Soulbound NFT**: Users draw personalized signatures, names, and star stamps directly onto the certificate via canvas, minting a truly unique on-chain relic using the micro-stars (0.00001 XLM) collected alongside their pet.

## 🕹️ Controls & Gameplay (操作方法)

| Button | Action | Description |
| :---: | :--- | :--- |
| **A** | **Feed Star (エサ ⭐)** | Drops a shining star for your pet to eat. Increases Hunger & Growth gauges. |
| **B** | **Tea Party (お茶会 ☕)** | Invites a wandering star pet for tea. Boosts happiness & accelerates growth. |
| **C** | **Constellation Gallery (星座録 🌌)** | Views your historical gallery of minted celestial certificates. |

---

## 🎨 Technology Architecture

- **Frontend**: Pure Lightweight HTML5 Canvas + Web Audio API (Retro 8-bit Synthesizer) + CSS Scanline CRT shader.
- **On-Chain Relic**: Zero-cost micro-minting powered by **Stellar / Soroban** smart contracts (0.00001 XLM gas fee).
- **Wallet Companion**: Seamlessly links with **StarPocket** as the permanent collector's vault.

## 🚀 Quick Start (Local Run)

Simply open `index.html` in any modern web browser, or serve with any static HTTP server:

```bash
# Python
python3 -m http.server 8080

# Node.js
npx serve .
```
